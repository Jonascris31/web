# Cupons de Amor

Projeto pessoal desenvolvido como presente de aniversário.

A aplicação apresenta uma carta e um conjunto de cupons interativos, com estados de resgate e acompanhamento visual do progresso.

## Objetivo

O projeto foi criado para praticar fundamentos de desenvolvimento web enquanto produzia uma experiência afetiva e personalizada.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Animações com `@keyframes`
- Manipulação do DOM
- Armazenamento local no navegador

## Funcionalidades

- Exibição de cupons em layout responsivo
- Resgate individual de cupons
- Registro visual dos cupons utilizados
- Barra de progresso dinâmica
- Persistência do estado no navegador
- Animações e efeitos de interação
